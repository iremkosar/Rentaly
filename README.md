🚗 Rentaly - AI Destekli Araç Kiralama Platformu

Rentaly, modern web teknolojileri ve yapay zeka entegrasyonu ile geliştirilmiş, kullanıcı odaklı ve dinamik bir araç kiralama sistemidir. Proje; güçlü admin paneli, akıllı veri yönetimi ve otomasyon süreçleri ile gerçek dünya senaryolarını hedefler.

✨ Proje Özellikleri

🎬 Dinamik Ana Sayfa

🚘 Araç Listeleme & Filtreleme

Araç türüne göre filtreleme (SUV, Sedan, Hatchback vb.)
Araç müsaitlik durumu
Kapı sayısı, fiyat ve teknik özellikler
Gelişmiş filtreleme sistemi

⚠️ Özel 404 Sayfası
Kullanıcı deneyimini artıran tasarım
Hatalı sayfalarda yönlendirme

📬 Rezervasyon Sistemi
Kullanıcı form doldurarak rezervasyon oluşturur
Form verileri anlık olarak admin paneline düşer

📊 Admin Paneli

Toplam araç sayısı
Aktif / bekleyen rezervasyonlar
Müşteri sayısı
Dinamik istatistikler (EF Core + LINQ)

📨 Rezervasyon Yönetimi
Kullanıcıdan gelen talepler admin paneline düşer

Onay / Red işlemleri yapılır

📧 Otomatik Mail Sistemi

Rezervasyon onaylandığında müşteriye
profesyonel ve güçlü e-posta gönderimi

🧩 Teknik Altyapı

⚙️ ASP.NET Core (N Katmanlı Mimari)

🧱 Entity Framework Core

🗄️ MSSQL Server

🎨 Bootstrap / Tailwind CSS

🔄 AJAX & Dinamik veri işlemleri

📬 SMTP Mail Servisi

🔄 Sistem Akışı

Kullanıcı araç seçer ve rezervasyon formunu doldurur

Veriler admin paneline düşer

Admin rezervasyonu inceler

Onay / Red işlemi yapılır

Onay sonrası kullanıcıya otomatik güçlü e-posta gönderilir
